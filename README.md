## 🚀 Getting Started

### Prerequisites

- A C++ compiler such as [g++](https://gcc.gnu.org/) or any IDE that supports C++ (e.g., VS Code, Code::Blocks, Dev-C++)

### Compiling and Running

Clone the repository:

```bash
git clone https://github.com/Kabeer0700-gif/DSA_Cpp.git
cd DSA_Cpp
```

Navigate to the desired lab folder and compile any `.cpp` file, for example:

```bash
cd Lab03
g++ filename.cpp -o filename
./filename
```
